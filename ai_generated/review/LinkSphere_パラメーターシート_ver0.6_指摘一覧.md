# LinkSphere パラメーターシート ver0.6 指摘一覧

- 対象: `LinkSphere_パラメーターシート_ver0.6_スタック実機反映.xlsx`（7 シート）
- 確認方法: 全シートの全セル値・セル結合・コメント・数式を抽出して突き合わせ、LibreOffice で PDF 化して見た目も確認した
- 「（意見）」は設計上の提案、「（要確認）」は実機や製品仕様で確かめてほしい点。それ以外はファイル上で確認できた事実

## 1. 壊れている・明らかな誤り（最優先）

### 1-1. C48T4XE-L シートのレイアウトが崩れている

行 25 付近から下で、セル結合が他シートより 1 行ずれています。結合範囲に値が飲み込まれ、次の項目が表示されないか消えています。

- 見出し: A30「ホスト名」、A31「コンソール認証」、A36「SSH」、A38「管理アクセスACL」、A40「ユーザーインターフェース」、A44「時刻設定」、A58「VTP」、A62「BPDU Protection」、A102「Vlanif設定」、A118「備考」、AY 列の各「備考」
- 値: AO37「3回」、AE38「SNMP：未設定」、K45「UTC（default）」、U60「MSTP（default）」、U61・AO61 のタイマー値、K66・AE66 の Interface STP 値
- 表の見出し: Trap Server の列見出し（K54〜AO54）、VLAN の Name 列、Vlanif と Routed Port のサブ見出し（No / Name、VRID、VIP など）
- 行 27 に「Hostname / Domain-name」の行が、機器構成情報の中へ紛れ込んでいる
- 行 26（SFP+／DAC／AOC）の「製品型番／個数」欄がない
- 「ポート構成情報」（ポート図・凡例・固定ポート構成の備考）が丸ごとない
- コメント「v3の場合は認証等の設定が必要」が U52・U53 にずれ、SNMP Access などの行を指している

対処案（意見）: 実機確認済みの C24T4XE-L シートを複製し、C48T4XE-L の機種固有値だけを入れ直すのが安全です。

### 1-2. 10GE のポート番号がシート間・シート内で食い違う

| シート | ポート図（行 126） | ポート設定表 |
|---|---|---|
| C8T4X-Q-L / C8P4X-Q-L / C24P4XE-L / C48LP4XE-L | 10GE 1/1/1〜1/1/4 | 10GE1/0/1〜1/0/4 |
| C24T4XE-L（実機確認済み） | 10GE 1/0/1〜1/0/4 | 10GE1/0/1〜1/0/4 |

実機確認済みの C24T4XE-L は図も表も 1/0/x です。1/1/x と書いた 4 シートのポート図が誤りの可能性が高いです（推測）。

### 1-3. 製品名が一致しない

- C24T4XE-L の AI14 が「LinkSphere C24-L」。O14 は「LinkSphere C24T4XE-L」
- AI14 は見出しがなく、何の欄か分かりません。C8T4X / C24P4XE / C48T4XE では O14 と同じ値、C8P4X / C48LP4XE では空欄です

### 1-4. 不明な文字列が残っている

- C24P4XE-L の BE124 に「Cf」（ポート構成情報の右上）

### 1-5. 行 22〜24 の値が切れて読めない

O22〜O24 は 1 列だけのセルで、右隣の P:R が結合セルのため文字がはみ出せません。画面でも印刷でも、次のように切れます。

- 「内蔵AC電源」→「内」、「非対応」→「非」、「PWR1：正常」→「PV」
- AE24 の見出し「専用スタックポート」も「専用スタッ」で切れる

O22:AD22 のように結合し直してください。

### 1-6. 改訂履歴が実態と合っていない

- ファイル名は ver0.6 なのに、履歴は「第 2 版」の 1 行だけ
- 改訂日が「YYYY/MM/DD」のまま。改訂者・承認者が空欄
- 第 2 版なのに区分が「新規」、内容が「新規作成」
- ver0.6 の主題である「スタック実機反映」の記録がない
- 版数の表記（ver0.6 と「第 2 版」）がそろっていない

## 2. 実機確認済みの機種ほど記載が薄い・シートごとに項目がずれている

### 2-1. C8P4X-Q-L（AW11 に「実機確認済み」）の主要欄が空欄

- 空欄: ソフトウェアバージョン（O20）、システムソフトウェアファイル（O21）、電源構成（O22）、PoE対応（O23）、PoE最大設定電力（O24）
- C8T4X-Q-L の AW28 は「共通初期値は C8P4X-Q-L 実機の確認結果を横展開」と書いています。展開元の C8P4X-Q-L が空欄なのは逆です

### 2-2. C8P4X-Q-L だけ見出しが違う

- AE22「ファン」（他シートは「冷却方式」）
- A24「PoE最大設定電力」（他シートは「PoE給電能力」）
- AE24「製品型番」（他シートは「スタックポート」）。値欄もなく、別の行から残った見出しに見えます。スタックポートの記載が抜けています

### 2-3. C48LP4XE-L の主要欄が空欄

- ボードタイプ（O15）、ソフトウェアバージョン（O20）、システムソフトウェアファイル（O21）、AW11 の確認状況メモ

### 2-4. C24T4XE-L だけ項目名と中身の種類が違う

- A21 が「システムソフトウェア情報」で、値は「Memory 2048MB / Flash 1024MB」。他シートは「システムソフトウェアファイル」で、値は OS ファイル名
- A22「電源・ファン」の値が「PWR1：正常」、AE22「冷却方式」の値が「FAN1：正常」。見出しは冷却方式なのに値は稼働状態です。「正常」は状態表示コマンドの結果で、仕様や設定値ではありません
- O16「Member 1：Master」など英語表記（他シートは「メンバー1」）

## 3. スタック（ver0.6 の主題）で足りない項目

### 3-1. メンバー 2〜4 のポート設定がない

筐体情報はメンバー 4 台分あるのに、ポート設定表はメンバー 1（GE1/0/x、10GE1/0/x）だけです。GE2/0/x〜GE4/0/x の行、またはメンバーごとの表が要ります。

### 3-2. スタックに使うポートが分からない

- C8T4X-Q-L / C8P4X-Q-L は「専用スタックポートなし」です。業務ポート（10GE）をスタックに使う前提と読めますが、どのポートを使うかの欄がありません。ポート設定表では 10GE1/0/1〜4 がすべて「Switch Port / PVID 1」のままです
- C24 系・C48 系は「専用スタックポート 2 ポート」とありますが、ポート図にもポート設定表にも出てきません（C48T4XE-L の AW24 も「CLI 上の物理インターフェース名は未確認」と記載）

### 3-3. スタックの設定項目が Stack Priority しかない（意見）

スタック構成で一般に決める項目の欄がありません。製品のスタック仕様に合わせて、要るものを足してください。

- メンバー ID
- スタックドメイン
- スタックポートの割り当て
- 複数マスター検知（スタックが分断したときに両方がマスターになるのを防ぐ機能）

### 3-4. マスターになる筐体が優先度で決まらない（意見）

全メンバーが Priority 100 のままです。C24T4XE-L は「Member 1：Master」と書いていますが、優先度が同じなので記載と設定が噛み合いません。マスターにしたい筐体の優先度を上げた推奨値を書くことを検討してください。

### 3-5. スタック台数の上限（要確認）

筐体情報は 4 台分で固定です。製品の最大スタック台数と合っているか確認してください。

## 4. ホワイトラベル製品として気になる点

### 4-1. OEM 元の情報が見える

- O20「V600R025C00SPC500」はOEM 元のバージョン体系です
- O21「S5735-V2_V600R025C00SPC500.cc」はOEM 元の型番を含む OS ファイル名です（C8T4X-Q-L / C24P4XE-L / C48T4XE-L）
- お客様情報欄があり、顧客へ渡す前提と読めます。顧客版は SphereOS のバージョンだけにするか、社内版と顧客版を分けることを検討してください（意見）

### 4-2. 社内向けの作業メモが本文に残っている

- AW11「個体値・型番表示・OSファイルは実機未確認」、AW24「CLI上の物理インターフェース名は当該機種の実機では未確認」、AW28「…横展開」、O20 の「代表機確認値：」
- 顧客版では消すか、別の「確認状況」シートへ移してください（意見）

## 5. 他社機のテンプレートの名残と思われる用語（意見）

OS の CLI 用語にそろえると、設定投入時の読み替えミスが減ります。

- 「VTP設定（非該当）」の節自体が不要です。VTP は Cisco 独自のプロトコルです（[Cisco: Understand VLAN Trunk Protocol (VTP)](https://www.cisco.com/c/en/us/support/docs/lan-switching/vtp/10558-21.html)）
- ポート図の「Gi」（C8P4X-Q-L だけ「GE」）。ポート設定表は「GE1/0/x」です
- ポート設定の Mode「Switch Port」、STP 列の「PortFast」「BPDU Guard」「Loop Guard」。STP 設定の節は「Edge」「BPDU Protection」なので、同じシートの中で用語が混ざっています
- 「ポートチャネル設定」と「Eth-Trunk設定」が混在
- 静的ルートの「Distance」
- VRRP の列「Hello/Hold」。Hold は HSRP の考え方です（[Cisco: Troubleshoot HSRP Common Issues](https://www.cisco.com/c/en/us/support/docs/ip/hot-standby-router-protocol-hsrp/10583-62.html)）。列見出し「Track Interface/Priority Decre」も途中で切れています
- 「Enable Password（不要）」と、備考「SSHを設定する場合は、Domain-nameも設定して下さい。」。ドメイン名が要るのは Cisco IOS で RSA 鍵を作るときの手順です（[Cisco: Configure SSH on Routers](https://www.cisco.com/c/en/us/support/docs/security-vpn/secure-shell-ssh/4145-ssh.html)）。SphereOS で要るか実機で確認し、不要なら備考を消してください（要確認）

## 6. 設定値の矛盾・不足

1. **SSH を受け付けるインターフェースの欄がない**: VTY は「許可：SSH」なのに、システム初期設定は「SSH Server Source：全インターフェース無効」です。このままでは SSH で入れない構成と読めます
2. **管理インターフェースの方針がシートで違う**: 全シートに「MEth0/0/0（論理IF）／Route Port」があります。一方、C48T4XE-L の AW72 だけ「専用物理 Management LAN ポートではない。管理 IP は Vlanif 利用を基本とする」です。方針を全シートでそろえ、Vlanif を使うなら管理 VLAN と管理 IP の記入欄を明示してください
3. **SNMPv3 の記入欄がない**: 初期設定は SNMPv3 なのに、Trap Server 表の列は「Trap Community」（v1/v2c の項目）です。v3 のユーザー名・認証方式・暗号方式・セキュリティレベルの欄がなく、コメントで「v3の場合は認証等の設定が必要」とあるだけです。SNMP Access の行も中身がありません
4. **Speed「Auto」と Duplex「Full」の組み合わせ**: 速度を自動にするなら、Duplex も自動（ネゴシエーション）にするのが一般的です。「Full」が固定設定か、ネゴシエーションの結果かが分かりません。固定と読まれると、対向機器とのデュプレックス不一致の原因になります（意見）
5. **ポートの種別の列がない**: VLAN 列は「PVID 1」だけで、access / trunk / hybrid の別と、許可する VLAN の列がありません
6. **PoE の設定列がない**: PoE モデル（C8P4X-Q-L / C24P4XE-L / C48LP4XE-L）のポート設定に、給電の有効/無効・優先度・上限電力の列がありません
7. **MST リージョン名の欄がない**: MST Region は Revision と VLAN の対応だけです
8. **初期値の記入がまちまち**: 時刻・STP・SSH は既定値を書いてあるのに、LLDP・BPDU Protection・Eth-Trunk load-balance・バナーは空欄です。空欄が「未設定」なのか「未確認」なのか区別できません
9. **ホスト名の欄が 2 か所**: A13（ハードウェア構成情報）と A30（管理アクセス設定）。片方を参照式にして、二重管理をなくしてください
10. **Time Zone が「UTC（default）」**: 国内へ納めるなら、JST（UTC+9）を推奨値として書くことを検討してください（意見）
11. **管理アクセスの制限がない**: 管理アクセス ACL が SSH・Web・SNMP とも「未設定」で、Web Manager は HTTPS 8443 で有効です。初期状態のまま運用されないよう、推奨設定（ACL の適用、または Web の無効化）を備考に書くことを検討してください（意見）

2. AW 列のメモ（AW11・AW24・AW28・AW72）が表の右外へはみ出し、印刷すると途中で切れます
3. ポート設定表の「Switch Port」が「Switch I」に、STP 列の「disabled」が詰まって切れます
4. C8T4X-Q-L はポート設定表の下に空行が 23 行残っています。ポート設定表の下の「備考」欄は C8P4X-Q-L にだけあります
5. 表記ゆれ
   - 「Stack Priority 」の末尾に空白（C24T4XE-L 以外の 5 シート）
   - 「100(default)」（半角括弧）と「100（実機確認値／default）」（全角括弧）

   - 「メンバー1」と「Member 1」
